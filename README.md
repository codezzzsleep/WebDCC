# WebDCC

WebDCC 是一个部署在个人公网服务器上的网页端，在同一个页面里驱动 **DeepSeek Harness**、**Codex**、**Claude Code** 三个原装 Agent：三者平级、各自以原生形态运行（系统提示词、内置工具、用户自己的配置一律不改），平台只负责启动、原样转交用户输入、原样展示输出，并提供 DSH 式的界面、一切皆有的固定 URL、以及弱网可用的同步与离线缓存。

功能范围、硬约束（第 3 节"原装原则"）、界面规格、协议与里程碑全部以 [SPEC.md](SPEC.md) 为准；界面蓝本截图见 [docs/reference/dsh/](docs/reference/dsh/)。
