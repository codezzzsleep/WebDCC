# Claude 服务端回收时的任务观察（#228）

服务端回收会先拒收旧运行实例的后续事件，然后关闭适配器；#223 的适配器关闭观察因此被拒收，持久任务却仍显示运行。Manager 现在记录最后一份通过来源、owner 和 generation 校验并成功保存的 query 身份，在回收路径中自行保存该实例的 unavailable 观察。原生迟到输出仍受原来的校验约束。

该观察只证明旧 query 的观察通道不可用；它不证明原生任务已退出。活动任务恢复为 unknown，原 nativeStatus、终态、run/工具/输出和原装 SDK 消息保留。原生关闭失败继续返回失败；观察保存失败也继续关闭自己持有的 query，并明确返回保存失败。

验证包括真实生产 Manager/ClaudeAdapter/SQLite 与无模型的受控 Query：dispose/disposeAll、公共事件 API 恢复、数据库重开、终态与原始信封保留、其他来源和迟到输出拒收、关闭及存储失败。该本地证据不证明官方 CLI、当前 Provider、实际原生停止或目标平台部署；失败和未触发范围由私有验收台账保留。
