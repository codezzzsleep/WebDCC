# DSH timed question recovery

When the native request declares `wait.timed`, an authenticated browser answer surface opens `userQuestions/attachWait` for its exact native Agent and call. The countdown starts from the Host's opening `remainingMs`. Receiving a waterfall alone does not create a claim. Each browser socket owns its stream; socket close, unsubscribe, source runtime disposal, or native connection replacement releases it.

The card owns the countdown and panel state across component mounts. Focus pauses a pristine countdown; blur resumes the remaining duration. The first edit and “多给我一些时间” stop automatic continuation. Drafts and that local wait choice persist by WebDCC Session, native Agent, call and question item. A hidden panel keeps counting, and the same call stays hidden when its native foreground changes to continued. A new Client restores its persisted draft. Sensitive values use page memory only.

On expiry WebDCC returns the official `$events/result` rejection, retaining the actual `clientId`, waterfall `eventId`, `UserQuestionError` and `ASK_TIMED_OUT`. An HTTP ACK records submission only. The native claim remains until the Host accepts the outcome and closes its stream, or the browser disconnects. A timed `tool/result` with matching pending call or authoritative `userQuestions.active` continuation then enables `userQuestions/answer` for that same call. It creates no replacement prompt. Full native answers or `userQuestions.settled` supply the business terminal state.

Native continuation proves that the old foreground attempt returned no answer. It releases that attempt's interaction lock and records its failure. A new late answer is explicit. Old foreground callbacks retain their own answer snapshot and cannot clear a new attempt's sending lock, claim its receipt, or reopen a native terminal result. An old forwarding cancellation cannot overwrite a late answer's submitted UI row.

The default native legacy tool has no timed wait. Its existing answer path stays indefinite. Native tool-call identity inferred for result matching does not manufacture a timed UI or a named native card. The official timed tool's indefinite form (`wait.callId` without `timed`) keeps a named draft and hide/reopen surface without a countdown. Direct human interaction with delegated native children remains unavailable (`DELEGATED_CALLER`).

The protocol check includes the official `rejected` carrier, with required name/message and optional code/details. Native installation, prompts, tools, permissions and version are unchanged. An expired or ended claim is never shown as a successful answer; a new connection must acquire a current opening, and stale browser replies are ignored by request identity.

Source regressions cover actual local HTTP/mux and browser sockets, native IDs and error shape, foreign claim rejection, old opening frames, foreground/late-answer races, focus/blur, edit/hold, hidden expiry and draft recovery.
