# 工作区文件创建边界

新建文件和目录固定 Linux 父目录描述符，核验其真实路径和工作区根目录身份后，通过 `/proc/self/fd` 中的描述符路径创建。文件使用独占创建，已存在的文件、目录和符号链接不能被覆盖；工作区内部目录链接解析后保留规范目标路径。

运行环境需要 Linux 和可用的 `/proc/self/fd`，无法核验的环境返回 501。此平台限制与工作区读取边界的独立开发交付相同，其它平台的等价实现仍需开发和验收。

如果创建期间父目录被移动，已固定的描述符不会把操作导向替换后的目录。原目录可能已有本次创建的入口；接口返回 409 并要求核对原目录，避免报告原请求路径成功。调用方应重新加载并检查结果，不自动重试。失败写入同样不代表文件系统没有发生任何变化，剩余原目录入口须核对。

此行为对应 #149、NP-13 #55 和总 #42。读取、保存最终提交、列目录以及完整认证和上传边界分别跟踪，开发回归不代替实际目标平台的独立验收。
