# 工作区 HTML 页面预览与文件下载

关联 [#136](https://github.com/codezzzsleep/WebDCC/issues/136)、[#133](https://github.com/codezzzsleep/WebDCC/issues/133)、文件能力总范围 [#68](https://github.com/codezzzsleep/WebDCC/issues/68)。实施基线为 main `dede68d85eac40a60556d1636bd57dc55fe70176`。

此前在文件面板打开 HTML，只显示 Markdown 代码块；二进制文件提示只能下载，却没有下载入口。本次把 HTML 默认切到页面效果，并为文件面板提供直接下载。

## 用户可见行为

- 在会话的“并排 → 工作区文件”选择 `.html` / `.htm`，直接看到浏览器渲染结果。
- “页面 / 源码”切换保留文本编辑。未保存的 HTML 可以先预览；保存沿用现有文件版本检查和草稿恢复。
- “刷新预览”重新加载入口及资源；“新窗口预览”提供更大的查看区域。
- 相对资源按 HTML 所在目录解析；工作区根路径的 CSS、图片、模块导入、fetch 和常见动态资源地址留在当前预览工作区。
- 需要 CDN 样式、脚本或 HTTPS API 的页面，可开启“允许页面联网”。这个选择属于当前文件，切换源码不丢失，切换另一文件后重新选择。
- 文本、HTML、图片、二进制和超过文本预览上限的文件都有“下载”。下载取磁盘上的完整原文件；未保存的编辑不会替换下载内容。
- 二进制文件展示可下载说明，避免空代码块中出现 `undefined`。

## 实现边界

文件层由 WebDCC 共用，未改三家 Harness 的提示词、工具或运行行为。HTML 预览使用 `sandbox="allow-scripts"` 的独立文档，没有 `allow-same-origin`、表单提交或顶层导航权限。预览使用最长 30 分钟、最多 256 份的内存读取凭据，只对应当前工作区；服务重启后重新打开即可建立新预览。

主应用认证仍用于建立预览和下载原文件。预览资源不需要应用 Cookie，提供 opaque-origin 模块和 fetch 所需的 CORS；本地连接限定预览路径，源目录及符号链接边界复用工作区文件解析。打开 HTTPS 资源不解除主页面、存储或应用写入的隔离。

HTML、CSS 和模块路径只在预览响应里处理；磁盘和原始下载字节不改。UTF-8 页面/资源会明确返回字符集。页面资源上限 32 MiB，编辑草稿预览上限 1 MiB。浏览器内直接执行普通 HTML/JS；需要编译或后台服务的项目仍需其正常构建/服务。

应用 Service Worker 的页面回退排除 `/workspace-preview/`，避免把 HTML 入口错误替换成 WebDCC 自身的应用壳。
