## 原生模拟器操作

使用 Android 8.0 / API 26、720 × 1280 的模拟器操作实际 APK。服务端直接使用 WebDCC 上游的 Fastify 路由、SQLite 存储、命令分发、会话管理和 WebSocket Hub。验收 Agent 是可控的测试适配器，修改隔离样例项目中的真实文件。

已验证：

1. 完整 token 链接绑定、覆盖安装后恢复已绑定连接。
2. 创建任务，中文需求逐字到达服务器；原生流式输出、代码块和改动入口。
3. diff → 源文件 → 返回恢复 diff；点击行号添加意见，先放入输入框确认。
4. 离开并重新进入任务，保留草稿。
5. 待审批时追加要求，显示排队；处理审批和提问后，排队消息只开始一次。
6. 回答同时包含选项 ID 和补充文本；关闭并重新打开问题面板保留填写内容。
7. 等待审批的任务可以停止；服务端记录 interrupted。
8. 服务端明确拒绝一次发送后，点击重试成功，原文仅入库一次。
9. 断线输入消息，强制关闭并重启应用，待发送消息仍然存在。
10. 网络恢复后，离线消息只入库一次。

11. 从历史阅读位置发送消息，自动定位到刚发出的消息，输入框清空并退出键盘焦点。
12. 从安卓系统文件选择器选择文件，返回原任务后完成分块上传，在输入框插入可见引用；服务器上的样例项目收到同样的文件内容。

最终包使用 R8 压缩，APK 约 1.7 MB。覆盖安装后的登录恢复、最终包启动和原生界面操作已验证。录屏为最终原生 APK 连接上述隔离测试服务的实际画面，验收模型名称为 `qa-model`；测试项目和模型没有打包进 APK。
